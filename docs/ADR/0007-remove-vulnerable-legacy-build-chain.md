# Remove the vulnerable legacy UI build chain

2026-11-17. Requirement C01 in ENTERPRISE_GAP_ANALYSIS.md. Engineering decision, no external deployment or product-permission expansion.

The final E3 full npm audit failed on GHSA-fc5q-39xc-vjpf. The existing bounded, readonly/no-network reproduction established a picomatch4.0.7 event-loop stall; it did not prove remote AgentBrake exploitability. A fresh advisory lookup still reports no patched release and proposed upstream PR237 remains open. `npm explain picomatch` identifies only the root Vite6.4.6 build chain. The supported product dashboard is separately built with Next; Vite supplies the legacy/disposable React UI only.

Decision: remove Vite and plugin-react and directly pin the already present maintained esbuild0.28.2 for that React/TS/CSS entry. Keep existing UI and server API, Next product build, authorization and scanner thresholds. Build output remains dist/index.html with JS/CSS and favicon. The local development middleware builds in memory on request and serves only named public artifacts; it does not open another port or expose repository/source/secret files. Development requires manual page reload, with no Vite React fast-refresh. Build errors return503 in development. No dependency override, unreviewed fork, audit exception or hidden scan exclusion.

Acceptance: absent vulnerable lock/installed graph, real asset build and Chromium rendering for both static and development modes, API/file boundary tests, TypeScript and full native/product/isolated/Enterprise lifecycle checks, fresh root/dashboard audit and exact image scan. Same-source package and Linux acceptance are separate requirements; successful focused checks alone do not close C02 or commercial acceptance.

Evidence: `evidence/build-dependency-remediation/`. Initial tests failed because the vulnerable graph existed and new builder was absent.
