## Review focus / acceptance failures to test

1. Duplicate bootstrap, invite replay/expiry and forged role cannot obtain authority (task1).
2. Disable/password/role change invalidates existing sessions, including last-admin races (task1 + task2).
3. User can complete setup and invite from actual UI without daily filesystem editing; errors remain actionable and never reveal credentials (task2).
4. Backup/restore failure cannot overwrite a previous install, leak plaintext artifacts or reactivate old grants; source resumes correctly (task3).
5. Restart/upgrade preserves action/audit/identity state and the same existing agent restrictions (task4).
