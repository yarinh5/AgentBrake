# Disposable installed Enterprise acceptance

The new `scripts/verify-enterprise.mjs` verifier builds a unique minimal HTTPS installation, bootstraps its existing managed owner, stops it, and enables synthetic OIDC/SCIM/audit delivery with the production configuration writer. `infra/product/verify-enterprise.compose.yaml` attaches a synthetic TLS IdP/audit sink to an internal enterprise-outbound network; it publishes no fixture port. The real product entrypoint, secret/config mounts, fixed-route enterprise egress, PostgreSQL identity state, dashboard proxy and TLS ingress are exercised. The installed `product-local` is outside this verifier's scope.

Control, agent, protected, dashboard and both enterprise networks are internal, with only the candidate's HTTPS port published on 127.0.0.1. The product's existing dedicated `loopback-ingress` publication bridge remains non-internal: Docker 29 does not publish the host port through an internal bridge. Only the fixed-destination, credential-free ingress service joins that bridge; the verifier tests agent denial for its addresses too. Build-time public pinned image/package downloads are authorized; no real GitHub App, external IdP, SIEM, paid service or customer target is contacted. The fixture CA is trusted only by its own health checks and the verification egress service through `NODE_EXTRA_CA_CERTS`; certificate checking remains enabled. The host API client explicitly trusts the separate candidate certificate.

Required evidence: bootstrap, mounted enterprise requirements and secrets, signed OIDC token exchange via real egress, SCIM role/offboarding, durable acknowledged audit cursor across control restart, administrator status, agent denial for fixture/egress/private secrets, installed browser SSO/read-only-team behavior, unchanged source hash during execution, known-secret scan of archived evidence, and zero project-labelled containers/networks/volumes after cleanup. All credentials and certificates are generated only for the disposable installation and removed with its scoped files.
